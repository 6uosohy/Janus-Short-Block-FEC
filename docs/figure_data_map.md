# Figure and table provenance

Every published figure and table traced back to the script that produced it and
the data file it reads. Use this when a number needs to be checked or a figure
regenerated.

## Figures

| Paper | File | Plotted by | Reads |
|---|---|---|---|
| Fig. 1 — AWGN FH-BFSK 5-FEC BLER | `figures/fhbfsk_awgn_5fec_bler_ci_12dB.pdf` | `analysis/make_fig1_awgn.py` | `data/fhbfsk_awgn/fhbfsk_5fec_results.mat` |
| Fig. 2 — Decoding complexity | `figures/awgn_5fec_complexity_v2.pdf` | `analysis/make_fig2_complexity.py` | `data/fhbfsk_awgn/ascl_profile.mat` |
| Fig. 3 — UWA FH-BFSK 5-FEC BLER | `figures/fhbfsk_uwa_5fec_bler_ci.pdf` | `analysis/make_fig3_uwa.py` | `data/fhbfsk_uwa/fhbfsk_5fec_results.mat` |

`figures/` holds the artwork exactly as submitted, and each script redraws its
figure from the committed data. How exactly the redraw matches the file differs:

- **Fig. 3** — `make_fig3_uwa.py` regenerates `fhbfsk_uwa_5fec_bler_ci.pdf` byte
  for byte, creation timestamp aside.
- **Fig. 1 and Fig. 2** — a redraw matches visually but not byte for byte. Both
  submitted PDFs were passed through Ghostscript (`-dNoOutputFonts`) before
  submission to convert their text to vector outlines, so the shipped files
  carry no embedded fonts while a freshly drawn one does. Sub-pixel text metrics
  also shift between matplotlib releases.

All three figures share one palette and one marker set so that they read as a
series, and all three set `pdf.fonttype = 42`: matplotlib defaults to Type 3
fonts, and IEEE PDF eXpress rejects Type 3.

## Tables

| Paper | Source | Notes |
|---|---|---|
| Table I — Five-FEC configurations | hand-written in the `.tex` | Parameters as configured in `src/fec/` |
| Table II — AWGN coding gain | `data/tables/fhbfsk_awgn_5fec_coding_gain.tex` | Auto-generated by the AWGN campaign |
| Table III — Per-frame complexity | hand-written in the `.tex` | Analytic operation counts; ASCL floor cross-checked against `ascl_profile.mat` |
| Table IV — UWA performance | `data/tables/fhbfsk_uwa_5fec_coding_gain.tex` | Auto-generated by the UWA campaign; the paper adds the pooled error-floor column |

The auto-generated tables use the label style `Polar (fix)` / `Polar (adp)`; the
paper renames these to `Polar-Fix` / `Polar-Adp` and adds the interpolation note.
Threshold values in the auto-generated tables are rounded to one decimal place,
while gains are computed before rounding — which is why Table II shows Conv and
Turbo both at 8.8 dB with a nonzero gain.

## Result file contents

### `fhbfsk_5fec_results.mat` (both AWGN and UWA)

| Variable | Shape | Meaning |
|---|---|---|
| `mode_names` | 1×5 cell | `Conv`, `Turbo`, `LDPC`, `Polar-Fix`, `Polar-Adp`, in row order |
| `bler` | 5×25 | Block error rate per code per SNR point |
| `ber` | 5×25 | Bit error rate |
| `nframes` | 5×25 | Frames actually simulated (early stop at 300 frame errors) |
| `nerr_frame` | 5×25 | Frame errors observed |
| `nerr_bit` | 5×25 | Bit errors observed |
| `ci` | struct | `.lower`, `.upper` — 95 % Wilson interval, both 5×25 |
| `gains` | struct | Interpolated thresholds and coding gain vs. Conv |
| `fhbfsk_cfg` | struct | Full configuration of the run — the authoritative record |

`fhbfsk_cfg` is what makes the runs reproducible: it carries `ebn0_db`,
`max_frames`, `min_frame_errors`, `rng_seed_base`, the polar/turbo/LDPC settings,
and the UWA channel parameters actually used. Read it before trusting any recipe:

```matlab
d = load('data/fhbfsk_uwa/fhbfsk_5fec_results.mat');
disp(d.fhbfsk_cfg)
```

### `ascl_profile.mat`

| Variable | Meaning |
|---|---|
| `ebn0_db` | 5:0.5:12 |
| `avg_attempts` | Mean number of SCL passes per frame (1 = no expansion) |
| `avg_list_size` | Mean final list size |
| `bler` | Polar-Adp BLER over the same grid |
| `L`, `L0` | 8 and 4 |
| `max_frames` | 5000 per point |

Fig. 2's bottom panel converts `avg_attempts` and `avg_list_size` into effective
operations per frame; the ~3,584-operation floor is `L0 * N * log2(N)` with
`L0 = 4`, `N = 128`.

## Audit trail

The UWA campaign was run once, end to end, and its console output is preserved
verbatim in [`../experiments/logs/uwa_run_log.txt`](../experiments/logs/uwa_run_log.txt):
the configuration banner, the (144,64) LDPC construction and its rank check, the
noiseless round-trip sanity check, and the per-SNR BLER/BER of all five codes as
they were measured. Every number in Table IV can be read back out of it.
